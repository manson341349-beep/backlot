# 场景设定卡：模板和例子

> Backlot 片场 v1.4.1 · Manson AIGC · CC BY 4.0

设定卡是整个场景的"唯一说法"。母图、白模、每张派生图的提示词，都以它为准。卡改了就升版本号（v1 → v2），旧版留着不删。

## 模板

```markdown
# <场景名> · 场景设定卡 v1

## 一、一句话定位
<什么地方、哪个年代、什么时间、什么天气、新旧程度，一两句>

## 二、坐标系
原点 = <哪个点，比如西南墙角的地面>。X 往东，Y 往北，Z 往上，单位米。

## 三、尺寸依据
<按现实里同类建筑的尺寸定，写一句依据>

## 四、构件表
| 构件 | 位置 / 尺寸（米） | 朝向 / 状态 | 备注 |
|---|---|---|---|
| 墙、门、窗、家具、固定陈设…… | X a～b，Y c～d，高 h | 门开 / 关，按这一场剧情 | |

## 五、光源
固定光源（属于场景，进场景图）：
1. <光源> —— 在哪、什么颜色、几盏
事件光（跟镜头走，不进场景图）：
- <车灯、手电、屏幕光……>

## 六、必须有 / 不能出现
- 必须有：
- 不能出现：任何可读文字、标牌、标签；……

## 七、角度清单
| 角度代号 | 站在哪、看向哪 | 画面里必须有什么 | 用在哪些镜头 |
|---|---|---|---|

母图里看不到、没定的墙面：<比如母图机位拆掉的那面墙。派生机位要避开>

## 八、和剧本、分镜对不上的地方
<写清哪里对不上、为什么，交给负责剧本或分镜的人定。本技能不改剧本和分镜。>
```

## 写卡时的规矩

- **尺寸按真实建筑定**：一间老式办公室大约 5×4 米、层高 3 米上下；一条双车道大约 7 米宽；多层楼的天台通常几十米见方。不要拿分镜里"两人相距三步"去倒推整个场地，场地会被压小。人物站位放不进场地时，在场地里挪人，把间距问题告诉负责分镜的人。
- **门窗状态按剧情**：这一场门是开着还是关着、窗帘拉没拉，按剧本这一场写，白模也照这个搭。
- **灯要数清楚**：几盏、什么样子、在哪。"几盏灯"这种模糊写法，生成时数量一定会跑。
- **还没设计的道具留空**：卡上写"桌面留空，文件在镜头里另加"，不要先编一个。
- **母图定版后回写**：母图和卡在结构上对不上、而母图已经被接受，按母图把卡改成 v2，坐标从母图反推，再用白模叠母图核对。

## 完整例子：老式办公室（夜）

```markdown
# 老式办公室（夜）· 场景设定卡 v1

## 一、一句话定位
九十年代小城的一间私人侦探办公室，深夜，窗外下着小雨；家具旧但收拾得干净。

## 二、坐标系
原点 = 西南墙角地面。X 往东，Y 往北，Z 往上，单位米。

## 三、尺寸依据
按普通临街老楼二层的单间办公室：5 × 4 米，层高 3 米。

## 四、构件表
| 构件 | 位置 / 尺寸（米） | 朝向 / 状态 | 备注 |
|---|---|---|---|
| 房间 | X 0～5，Y 0～4，高 3 | | 水泥地，下半截墙刷绿漆 |
| 门 | 南墙，X 0.6～1.5，高 2.1 | 关着 | 单扇木门，上半截磨砂玻璃 |
| 窗 | 北墙，三扇竖窗，X 1.5～4.5，窗台高 0.9，窗顶高 2.4 | 关着，百叶帘拉起 | 窗外是对面楼的几点灯 |
| 办公桌 | 中心 X 2.5，Y 2.6；1.6 × 0.8，高 0.76 | 坐的人面朝南（朝门） | 木桌，四条腿 |
| 办公椅 | X 2.5，Y 3.2 | 面朝南 | 木椅，四条腿着地，有靠背 |
| 访客椅 | X 2.5，Y 1.8 | 面朝北（对着桌子） | 和办公椅同款 |
| 书柜 | 贴西墙，X 0～0.4，Y 1.2～3.6，高 2.2 | | 玻璃门，里面放旧卷宗 |
| 文件柜 | 贴东墙，X 4.5～5，Y 0.5～1.0，高 1.3 | | 铁皮四斗柜 |
| 衣帽架 | X 0.3，Y 0.35 | | 门边，挂一件风衣 |

## 五、光源
固定光源：
1. 吊灯 ×2：X 1.8 和 X 3.4，Y 2.0，灯罩底离地 2.5，暖黄，铁皮碗形灯罩朝下。
2. 台灯 ×1：办公桌东头，绿色灯罩。
3. 窗外：对面楼几点冷白灯，加雨水在玻璃上的反光。
事件光：无。

## 六、必须有 / 不能出现
- 必须有：两盏吊灯、三扇竖窗、磨砂玻璃门、书柜、四条腿的椅子。
- 不能出现：任何可读文字、标牌、日历上的字、屏幕；现代电器。

## 七、角度清单
| 角度代号 | 站在哪、看向哪 | 画面里必须有什么 | 用在哪些镜头 |
|---|---|---|---|
| 母图 | 拆掉东墙，从东边往西看（相机偏南、比吊灯略低） | 整个房间：左边南墙的门、右边北墙三扇窗、正对面西墙书柜、桌椅、两盏吊灯 | 定材质和光 |
| A | 拆掉南墙，从门外往北看 | 办公桌、办公椅、三扇窗、两盏吊灯 | 1、3、7 |
| B | 拆掉北墙，从窗外往南看（A 的反打） | 门、衣帽架、办公桌、访客椅、两盏吊灯 | 2、4 |
| 俯 | 正上方 | 全部家具、门窗、人物占位 | 内部核对 |

母图里看不到、没定的墙面：东墙（母图机位拆掉了它）。A、B 都不能拍到它。
```
