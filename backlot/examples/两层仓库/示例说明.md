# 示例三：两层旧仓库（室内 · 楼梯和二层走廊 · 白天）

> Backlot 片场 v1.4 · Manson AIGC · CC BY 4.0

这个示例演示有楼上楼下的空间：楼上的人和楼下的人怎么用一对机位对上；仰拍、俯拍常出什么问题；平面图看不出高度时，怎么加一张剖面。

**本示例没有出母图和派生图**，只给写好的提示词；文件夹里的图都是 Blender 白模渲染图（Blender 5.2 实测跑通）。提示词里"模型""报价"两栏留空，用的时候按你选的模型填。

这个示例的白模脚本和图还是上一版的做法：体块带颜色，投影检查是所有相机查同一张清单，没有未定墙面检查和露底检查。照它学怎么搭没问题；自己新做场景时，配色和检查按 `scripts/whitebox_template.py` 来（只用灰、按机位查）。

## 第 1 步 · 角度清单

假设分镜是这样一段：一个人站在二层走廊的栏杆后，另一个人站在一楼大厅里，两人隔着楼层说话（楼下仰看、楼上俯看，正反打）；最后楼下的人走楼梯上去。

| 角度代号 | 站在哪、看向哪 | 画面里必须有什么 | 用在哪些镜头 |
|---|---|---|---|
| 母图 | 一楼东南角、人眼高度往西北看 | 整个大厅：楼梯、二层走廊和栏杆、北墙窗、南墙高窗、两盏工矿灯、两堆木箱 | 定材质和光 |
| A | 楼下的人站的位置、人眼高度，仰头看楼上的人的脸 | 走廊前沿和栏杆、走廊下的钢柱、北墙窗、屋顶钢梁 | 1、3 |
| B | 楼上的人站的位置、人眼高度，低头看楼下的人（A 的反打） | 前景栏杆、一楼地面、东半边的木箱、南墙大货门 | 2、4 |
| C | 楼梯脚往上看 | 整段楼梯、楼梯扶手、走廊尽头、一扇北窗 | 5 |
| 平面 | 正上方，掀掉屋顶和走廊楼板 | 楼梯、走廊前沿线、柱子、木箱、机位标记、两个人的位置 | 内部核对，不挂给模型 |
| 剖面 | 拆掉东墙往西看 | 一楼地面、走廊高度、栏杆高度、灯和屋顶的高度、两个人的身高 | 内部核对，不挂给模型 |

有楼层的场景至少要两张核对图：平面看前后左右，剖面看高低。只看平面，"楼上的人能不能看到楼下的人""灯会不会挡在两人中间"都判断不了。

## 第 2 步 · 场景设定卡

```markdown
# 两层旧仓库 · 场景设定卡 v1

## 一、一句话定位
城郊一座停用多年的旧砖墙仓库，单层大厅里沿北墙加了一条钢结构二层走廊，西墙一部钢楼梯上去；白天，阴天，大厅里空荡荡的。

## 二、坐标系
原点 = 大厅西南墙角的地面。X 往东，Y 往北，Z 往上，单位米。

## 三、尺寸依据
大厅东西 24 米、南北 12 米，檐口高 9 米：常见的单层轻型仓库尺寸。
二层走廊地面高 4.2 米，栏杆高 1.05 米（工业平台护栏常见高度，凭经验，未查规范）；楼梯每级高 0.2、深 0.35。

## 四、构件表
| 构件 | 位置 / 尺寸（米） | 朝向 / 状态 | 备注 |
|---|---|---|---|
| 墙 | 四面砖墙，厚 0.25，高 9 | | 旧红砖，下半截刷过灰白涂料，大片剥落 |
| 屋顶 | 檐口 9 米；正好六道钢梁南北走向，X 2、6、10、14、18、22 | | 深色钢梁，屋面板在梁上 |
| 南墙大货门 | X 9～14，高 5 | 关着 | 推拉铁门，锈 |
| 南墙高窗 | 正好六扇，中心 X 2、6、10、14、18、22，各宽 2.2，窗台 6、窗顶 8 | | 钢窗框，玻璃脏，有几块碎 |
| 北墙窗 | 正好三扇，中心 X 6、12、18，各宽 2，窗台 5.6、窗顶 7.4 | | 在二层走廊里，从一楼仰头看得到 |
| 东墙小门 | Y 3～4，高 2.1 | 关着 | 单扇铁门 |
| 二层走廊 | 沿北墙通长，Y 9.5～12（进深 2.5），地面高 4.2 | | 钢板走廊，前沿一道钢边梁 |
| 走廊钢柱 | 正好四根，X 4、10、16、22，落在走廊前沿下 | | |
| 走廊栏杆 | 从 X 1.2 一直到东墙，扶手高 1.05，中间一道横杆，立柱每 2 米一根 | | 楼梯上来那一段（X 0～1.2）不装 |
| 钢楼梯 | 贴西墙，X 0～1.2，从 Y 2.5 起步往北上，到 Y 9.5 接走廊；正好 21 级 | | 镂空钢踏板，扶手只装在开敞的东侧 |
| 长工作台 | 走廊下面，X 8～11，Y 10.6～11.4，高 0.9 | | 旧木台面 |
| 木箱堆 1 | 靠南墙、货门西边，X 4～6.4，Y 0.3～1.5；两只并排、叠两层，共 4 只 | | 木箱边长 1.2 |
| 木箱堆 2 | 大厅东半边，X 18～19.2，Y 6.5～8.9；两只前后排、叠两层，共 4 只 | | |

## 五、光源
固定光源：
1. 南墙六扇高窗：阴天的天光从高处进来，照亮大厅中间的地面和北半边的墙。
2. 北墙三扇窗：更柔的天光，照亮二层走廊。
3. 工矿灯：正好三盏，挂在大厅上空 X 6、12、18，Y 4，灯罩高 6.6～7.0；白天不亮。
大厅四角和走廊底下最暗。
事件光：无。

## 六、必须有 / 不能出现
- 必须有：楼梯在西墙；走廊沿北墙；扶手只在楼梯东侧；楼上楼下的人之间没有东西挡着（灯挂在 Y 4，在两人连线的南边）。
- 不能出现：任何可读文字（墙上标语、编号、货箱上的字、警示牌）；叉车和现代设备；阳光照出的光柱和地面光斑（阴天）。

## 七、角度清单
（见上面第 1 步那张表）

## 八、和剧本、分镜对不上的地方
无。
```

为什么选阴天：晴天从高窗斜照进来的光柱和地面光斑很好看，但它们的位置由太阳方向决定，每个角度都得对上。模型各画各的，A 里光斑在左、B 里换了位置，剪到一起就穿帮。剧情不需要阳光，就选阴天；需要的话，在白模里打一盏方向光，把光斑的位置渲出来，挂在白模上一起给模型（这条是经验建议，本示例没有实测）。

母图里只看得到两盏灯（第三盏在画框外），所以写"两盏"，不写"三盏"——提示词写的是这张画面里有什么，不是场景里一共有什么。

调场景时改过的地方，记下来给你参考：

- **木箱挪过位置**：最早两堆箱子放在大厅中间，东边那堆叠三层，母图机位里把楼梯和走廊东段都挡住了。改成一堆靠南墙、一堆在东半边、都只叠两层，母图里楼梯和走廊都露出来了。
- **灯挪过位置**：工矿灯原来挂在 Y=5，A 仰拍时 1 号灯正好卡在画面左上角、只露半个。挪到 Y=4 以后，A 里三盏都不入画。半个灯在成图里很容易变形，要么完整入画、要么完全不入画。
- **重叠面出碎斑**：走廊前沿的边梁和楼板有一个面叠在同一个位置，渲染出来是一片碎斑。把边梁往外挪 1 厘米、顶面压低 1 厘米就好了。栏杆立柱和扶手也一样错开 1 厘米。
- **关掉投影**：有屋顶的室内开了投影，整个室内被压黑，楼板上还有一块块斑点。这一例关掉投影，只靠轮廓线和凹陷阴影（cavity）读形状。老街是室外，投影开着反而能看出路灯和楼的前后关系。

## 这个示例教什么

### 1. 楼上楼下怎么对上：对视点

两个人隔着楼层说话，A、B 两台相机都从"人的眼睛"出发：

- A 放在楼下的人眼睛的位置（离地 1.6 米），看向楼上的人的脸（走廊地面 4.2 + 1.6 = 5.8 米）。
- B 放在楼上的人眼睛的位置，看向楼下的人。B 看向的是楼下的人的胸口（1.0 米），这样楼下的人在画面里不会贴着下沿。

两台相机在同一条视线的两头，A 仰多少度、B 就俯差不多多少度（这一例两人水平距离约 6.9 米、高差 4.2 米，A 仰约 31°，B 俯约 35°）。仰俯角度由真实高差算出来，别为了"更有压迫感"把 A 拍成快要垂直的仰拍——那样和 B 接不上，观众会觉得两个人不在同一个空间里。

在平面图里，两个人物占位和 A、B 两个机位标记应该在同一条线上；在剖面里，看两人连线上方和中间有没有东西挡着（这一例的工矿灯在连线南边、高度在两人头顶上方，没挡住）。

### 2. 仰拍、俯拍常出的问题

下面是这类角度常见的问题和写法上的对策（经验总结；本示例没有出图，没有逐条实测）：

| 角度 | 常见问题 | 对策 |
|---|---|---|
| 仰拍 | 屋顶占掉大半个画面，走廊反而很小 | 白模里先调好屋顶占多少；提示词按白模写"画面上方是屋顶"，不写"高耸的屋顶" |
| 仰拍 | 竖线收拢得太厉害，墙和柱子像要倒下来 | 写"墙和栏杆是竖直的，只稍微往上收拢"；焦距别太广 |
| 仰拍 | 走廊底面画成了天花板，看不出是一条悬在半空的走廊 | 写清"走廊前沿一道钢边梁、底面背光、下面有钢柱撑着" |
| 俯拍 | 前景栏杆糊成一片，或者干脆消失 | 写清栏杆在前景、扶手和横杆的走向、立柱一根根排开 |
| 俯拍 | 地面上的东西缩成玩具大小 | 写清东西的真实大小（"边长一米多的大木箱"） |
| 俯拍 | 地面占满画面，看不出是在高处往下看 | 白模里保留一段远处的墙；提示词写"远处是南墙" |
| 都有 | 细栏杆数量和粗细每张不一样 | 白模里栏杆按真实间距搭出来，提示词不写具体根数，写"按参考图 2" |
| 楼梯 | 镂空楼梯画成了实心斜坡，或者一级级的台阶数对不上 | 写"一级一级镂空的钢踏板，能透过缝隙看到后面"；白模里每一级都单独搭 |

### 3. 平面加剖面

有楼层的场景，平面图（掀掉屋顶和楼板）看前后左右；剖面（拆掉一面墙，正交看过去）看高低。这一例平面里走廊楼板掀掉了，所以用一条黄线标出走廊前沿，看得出楼梯是从哪里接上走廊的。剖面里放两个人物圆柱，按真实身高，一眼就看得出楼上的人比楼下的人高出多少。

### 4. 画面里看不到的东西不写

母图看得到两盏灯，派生 A、B、C 里一盏都看不到，所以 A、B、C 的卡写"没有亮着的灯"，不写"三盏工矿灯"。写进去了，模型会想办法把灯画进来，构图就跑了。每张卡写之前，对着那张白模和脚本打印的投影检查核一遍：这个角度里有什么，就写什么。
