# 示例一：老式办公室（室内 · 单层 · 夜）

> Backlot 片场 v1.4 · Manson AIGC · CC BY 4.0

这个示例演示最基本的一条链：一个小房间，一张母图，一组正反打。别的场景先照着它走一遍，再看另外两个示例。

**本示例没有出母图和派生图**，只给写好的提示词；文件夹里的图都是 Blender 白模渲染图。提示词里"模型""报价"两栏留空，用的时候按你选的模型填。

## 文件

| 文件 | 是什么 |
|---|---|
| `示例说明.md` | 本文：整条链 |
| 白模脚本 | 就是 `scripts/whitebox_template.py`（模板脚本自带这个例子） |
| `老办公室_白模_v2_母图机位_拆东墙.png` | 母图机位白模（拆掉东墙） |
| `老办公室_白模_v2_A_门口往北.png` | 角度 A 白模（拆掉南墙，从门外往北看） |
| `老办公室_白模_v2_B_窗边往南.png` | 角度 B 白模（A 的反打；拆掉北墙，从窗外往南看） |
| `老办公室_白模_v2_椅子检查.png` | 内部检查：椅子腿都在、都着地 |
| `老办公室_白模_v2_俯视布局.png` | 俯视布局，核对位置用 |

图片是 1920 宽渲染后缩到长边 960 放进包里的，看布局够用；自己跑脚本出的是原尺寸。

白模是 v2：房间和家具没变，和 v1 比改了三处。每面墙做成一整块（v1 的墙是几块拼的，渲出来有竖线）；A、B 两台相机换了站位和焦距（v1 是 16、14 毫米的超广角，而且 A 拍到了母图里没有的东墙），现在都是 32 毫米；体块一律用灰、深浅拉开。

## 第 1 步 · 角度清单

| 角度代号 | 站在哪、看向哪 | 画面里必须有什么 | 用在哪些镜头 |
|---|---|---|---|
| 母图 | 拆掉东墙，从东边往西看（相机偏南、比吊灯略低） | 整个房间：左边南墙的门、右边北墙三扇窗、正对面西墙书柜、桌椅、两盏吊灯 | 定材质和光 |
| A | 拆掉南墙，从门外往北看 | 办公桌、办公椅、三扇窗、两盏吊灯 | 1、3、7 |
| B | 拆掉北墙，从窗外往南看（A 的反打） | 门、衣帽架、办公桌、访客椅、两盏吊灯（书柜在右边，只进来靠门的一头） | 2、4 |
| 俯 | 正上方 | 全部家具、门窗 | 内部核对，不挂给模型 |

为什么是这一套：房间只有两个人对坐说话，镜头只有"朝窗"和"朝门"两个方向，所以 A、B 一对正反打就够了。俯视只给人看。

母图里看不到、没定的墙面：**东墙**（母图机位拆掉了它）。A、B 都不能拍到它。

## 第 2 步 · 场景设定卡

用 `references/scene-card.md` 里的「完整例子：老式办公室（夜）」v1，这里不重复贴。几个后面反复用到的数：

- 房间 5 × 4 米，层高 3 米。原点在西南墙角地面，X 往东、Y 往北。
- 门在南墙 X 0.6～1.5，关着；北墙三扇竖窗 X 1.5～4.5。
- 天花板正好两盏吊灯，X 1.8 和 3.4；办公桌东头一盏绿罩台灯。
- 不能出现任何可读文字、屏幕、现代电器。

正文（和 `references/mother-image.md` 里的例子是同一段）：

> 九十年代小城一间私人侦探办公室，深夜，窗外下着小雨。从房间东边往西看，能看到整个房间。房间约五米乘四米，水泥地面，墙下半截刷旧绿漆、上半截米白。画面右边是北墙，三扇竖长木框窗，百叶帘拉起，玻璃上挂着雨水，窗外对面楼有几点冷白灯光。正对面西墙靠着一个两米多高的玻璃门木书柜，里面堆着旧卷宗。房间中间一张旧木办公桌，桌面空着，桌子东头一盏绿色灯罩台灯亮着；桌后一把木椅、桌前一把同款木椅，两把椅子都是四条腿着地、有靠背。画面左边是南墙，远端一扇单扇木门关着，门上半截是磨砂玻璃，门边立着衣帽架挂一件风衣；左边近处靠墙一个铁皮四斗文件柜。天花板正好两盏铁皮碗形吊灯，暖黄光往下照，桌面和地面一圈暖光，墙角落暗。真实拍摄的照片质感，暖黄和窗外冷蓝对比。画面里没有人，没有任何可读文字、标牌、日历和屏幕。

母图出来后按 `references/mother-image.md` 的自检表查，定版前不出派生图。

## 第 4 步 · 白模

```
blender -b --factory-startup -P scripts/whitebox_template.py -- <输出文件夹> <母图路径(可选)>
```

渲染图和自检（我逐张打开看过；数字是脚本打印的投影检查和未定墙面检查的结果）：

| A_门口往北 | (2.2, −3.0, 1.6) 看向 (1.50, 1.95, 1.43)，32 mm；南墙和门隐藏 | 必须有的 5 样都完整在画面内。左边是西墙和书柜，书柜左边是衣帽架；右半边是北墙三扇窗，窗前是桌椅，台灯在桌子右头；两盏吊灯一盏在正中上方、一盏在右上。东墙占画面 0.00%，没有露到房间外面 |

| 椅子检查 | 斜下方看访客椅 | 两把椅子四条腿都在、都着地 |
| 俯视布局 | 正上方正交 | 门、三扇窗、桌、两把椅、书柜、文件柜、衣帽架位置和设定卡一致 |

脚本开头还会先跑一次"未定墙面检查·自证"：让一台正对东墙的相机去查，报的是 69.61%，说明这个检查确实会报，A、B 的 0.00% 才可信。

## 这个示例教什么

- **小房间拆墙放相机**：站在屋里退不开，就把相机身后那面墙放进单独一组，这个角度渲染时隐藏，站到墙外去。母图拆东墙，A 拆南墙，B 拆北墙。站得开，焦距才能用到 20 毫米以上，画面里也才带得上吊顶、地面和墙角。
- **必须有什么要取舍**：这间房只有 5 × 4 米，B 这个角度没法同时装下整面书柜、两盏吊灯，又不拍到东墙、不露到房间外面（自动找过一遍站位，没有一个都满足的）。所以 B 的必须有里去掉了书柜，换成办公桌，并在对照表的使用条件里写明。
- **母图拆掉的那面墙，派生机位不能拍到**：东墙在母图里没出现过，长什么样没定。脚本对 A、B 各跑一次未定墙面检查，都是 0 才算过。
- **门在母图里很窄也照写**：斜着看门只剩一条边，提示词照样写清门在哪、关着，不然模型可能把那面墙画成没有门。
- **反打的左右**：从北往南看，西墙在右边。每张卡写之前对着白模核一遍左右。
- **椅子检查机位**：有腿的家具单独从斜下方渲一张，确认腿都在、都着地。白模里没腿，成图一定悬空。
