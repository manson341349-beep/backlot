# 示例二：雨夜老街（室外 · 没有天花板 · 夜雨）

> Backlot 片场 v1.4.1 · Manson AIGC · CC BY 4.0

这个示例演示室外场景和室内的不同：没有天花板，要处理天空和地平线；远处的东西怎么搭；尺寸怎么按真实街道定；街道两头都要有东西，反打才不穿帮。

**本示例没有出母图和派生图**，只给写好的提示词；文件夹里的图都是 Blender 白模渲染图（Blender 5.2 实测跑通）。提示词里"模型""价格"两栏留空，用的时候按你选的模型填。

这个示例的白模脚本和图还是上一版的做法：体块带颜色，投影检查是所有相机查同一张清单，没有未定墙面检查和露底检查。照它学怎么搭没问题；自己新做场景时，配色和检查按 `scripts/whitebox_template.py` 来（只用灰、按机位查）。

## 第 1 步 · 角度清单

假设分镜是这样一段：一个人冒雨沿街往北走（顺着街拍），回头看身后（反打），最后横穿马路走进对面一间亮着灯的小店。

| 角度代号 | 站在哪、看向哪 | 画面里必须有什么 | 用在哪些镜头 |
|---|---|---|---|
| 母图 | 街南头、二楼高度往北看 | 两排店面、四盏路灯、报刊亭、街尽头的楼、远处高楼轮廓、天空 | 定材质和光 |
| A | 街心、人眼高度往北看 | 2～4 号路灯、报刊亭、街尽头的楼、东侧两间亮灯的店 | 1、2、5 |
| B | 街心、人眼高度往南看（A 的反打） | 1～3 号路灯、报刊亭、街南头的楼 | 3 |
| C | 西侧人行道上横着往东看 | 整条路面的宽度、对面三间店面（中间那间亮灯）、两盏路灯 | 4、6 |
| 俯 | 正上方 | 全部店面、路灯、报刊亭、机位标记、人物占位 | 内部核对，不挂给模型 |

为什么要 C：A、B 都是顺着街看，街有多宽看不出来；"横穿马路"这个动作要一个横着看的角度，路面宽度才定得住。

## 第 2 步 · 场景设定卡

```markdown
# 雨夜老街 · 场景设定卡 v1

## 一、一句话定位
九十年代小城老城区的一条双车道老街，深夜，飘着细雨，路面湿透；两边是两三层的旧临街楼，大多数店已经关门。

## 二、坐标系
原点 = 街道中线南头的路面。X 往东（横穿街道），Y 往北（顺着街道），Z 往上，单位米。

## 三、尺寸依据
按常见城市支路：双车道每条车道 3.5 米，路面共 7 米；两边人行道各 2 米，路缘高 0.15 米。
老街临街铺面开间一般 3.6～4.5 米，这里统一 4 米；楼进深 8 米，高 6.5～9 米（两层到三层，高低错开）。

## 四、构件表
| 构件 | 位置 / 尺寸（米） | 朝向 / 状态 | 备注 |
|---|---|---|---|
| 路面 | X -3.5～3.5，顺街方向两头一直延出去 | 湿透，有浅积水 | 柏油 |
| 人行道 | 西 X -5.5～-3.5，东 X 3.5～5.5，Y -10～50，高 0.15 | | 水泥方砖 |
| 店面 | 每侧 15 间，每间 4 米宽，Y -10～50；店门 2.9 高 | 大多卷帘门拉下 | 每间门面上方一块空白招牌板（高 3.1～3.8），二楼两扇窗 |
| 亮灯开着的店 | 东侧从南往北第 3、8、12 间；西侧第 5、10 间 | 卷帘拉起，店里亮暖黄灯 | 正好 5 间 |
| 街两头 | 北头 Y 57～65 一排 10 米高的楼；南头 Y -25～-17 一排 9 米高的楼 | | 横街对面的楼，挡住视线尽头 |
| 远景 | 南北两头各 4～5 栋，离街 50 米以上，高 24～42 米 | | 只有体块，不做细节 |
| 报刊亭 | 西侧人行道，X -5.3～-3.9，Y 17～19.5，高 2.75（含顶檐） | 卷帘拉下 | 绿色铁皮 |

## 五、光源
固定光源：
1. 路灯 ×4：全在东侧人行道，X 4.9，Y 2、14、26、38；灯杆 6 米，顶上横臂伸向路面 1.2 米，扁平灯头朝下，橙黄钠灯光。
2. 亮灯的店 ×5：见构件表，暖黄光从门里照到人行道上。
3. 二楼窗户：全部黑着。
4. 天空：低阴云，被城市灯光从下面映亮，暗灰蓝。
事件光（跟镜头走，不进场景图）：过路车灯。

## 六、必须有 / 不能出现
- 必须有：四盏路灯都在东侧；报刊亭在西侧；街尽头有楼挡住，看不到街"到头就没了"。
- 不能出现：任何可读文字（招牌字、门牌、广告、路牌、车牌）；人；车；架空电线和电线杆；月亮和星星。

## 七、角度清单
（见上面第 1 步那张表）

## 八、和剧本、分镜对不上的地方
无。
```

两条按真实尺寸定的规矩，这一例都用到了：

- **街宽不拿人物走位倒推**：分镜里"走三步就到对面"，按真实 7 米路面加两边人行道，横穿要十几步。场地按真实尺寸搭，走位的问题告诉负责分镜的人。
- **灯要数清楚、写死在哪一侧**：路灯全在东侧，正打在右边，反打就到了左边。写成"街边几盏路灯"，每个角度都会各画各的。

## 第 4 步 · 白模

```
blender -b --factory-startup -P build_雨夜老街_v1.py -- <输出文件夹>
```

macOS 上 blender 在 `/Applications/Blender.app/Contents/MacOS/Blender`。脚本会在输出文件夹里建 `renders/` 放渲染图，并存一份 `.blend`。

渲染图和自检（五张我都打开看过；地平线和"在不在画面里"是脚本投影检查打印的数）：

| 渲染图 | 相机（位置 → 看向，焦距） | 地平线 | 自检 |
|---|---|---|---|
| 母图机位_南头高处往北 | (0.5, -8, 5.5) → (0, 30, 2)，22 mm | 画面竖向 0.60 | 四盏路灯头、报刊亭、北头的楼都完整在画面内；东侧第 3 间亮灯的店门在右下角被画框切到（它离相机太近，不影响定材质）；天空占上面约三成 |
| A_街心往北 | (-1.2, 0, 1.6) → (0.3, 45, 2.4)，28 mm | 0.48 | 2～4 号路灯头完整在画面内，1 号在相机身边、不在画面里；报刊亭、北头的楼、东侧第 8 和 12 间亮灯的店都在 |
| B_街心往南 | (1.2, 40, 1.6) → (-0.3, -5, 2.4)，28 mm | 0.48 | 1～3 号路灯头完整在画面内，4 号在相机身边、不在画面里；报刊亭、南头的楼、东侧第 3 和 8 间都在；和 A 左右对称 |
| C_西人行道往东 | (-4.8, 23, 1.75) → (6, 21, 3)，20 mm | 0.39 | 2、3 号路灯在画面里，一左一右；东侧第 8 间亮灯的店在正中；前景是整条路面和对面路缘 |
| 俯视布局 | 正上方正交，宽 46 米，1000×2000 | | 远景隐藏；四个机位三角标记（母图白、A 红、B 蓝、C 绿）、四盏路灯的黄色圆点、两个人物占位都看得清，人物没压在机位标记上 |

调相机时改过两次，记下来给你参考：

- A 最早站在 Y=6，2 号路灯头被画面上沿切掉一半。切掉一半的灯头，成图里容易变形或消失，所以把 A 挪到 1 号灯旁边（Y=0），B 对称挪到 4 号灯旁边（Y=40），重渲后三盏灯头都完整。
- 俯视图第一版对比度太低、画面太宽，看不清机位。加了彩色机位标记和路灯圆点，宽度收到 46 米。

## 这个示例教什么

### 1. 没有天花板：天空和地平线

- **白模里的天空只是一块平的底色**。不在提示词里写天空，模型可能照搬成一片平平的灰。每张卡都写清天空是什么样（这一例是"低低的暗灰蓝阴云，靠近地平线被城市灯光映亮"），并写"参考图 2 里的灰色天空只是底色"。
- **地平线高度要一致**：同样是人眼高度往前平看，地平线落在画面中间附近（这一例 A、B 都是 0.48）。两个角度的相机高度差很多，地平线就差很多，剪到一起会跳。脚本给每台透视相机打印地平线在画面里的竖向位置（0 是底、1 是顶），对一眼就知道。
- **母图站高一点**：母图是二楼高度（5.5 米），地平线在 0.60，路面多露一些，街道的走向和路灯的排列看得更清楚。
- **地面要铺得够大**：脚本里铺了一块 600 米见方的地，远景和地平线附近不会露出"地的边"。

### 2. 远处的东西：粗体块还是背景板

| 做法 | 什么时候用 | 这一例 |
|---|---|---|
| 粗体块（只有长宽高的方块，不做窗户和细节） | 两个以上方向都看得到远处；需要远处的楼在不同角度里有合理的透视和遮挡 | 用这个：A 往北、B 往南都看得到远处，南北两头各放了 4～5 个体块 |
| 背景板（一张竖着的平面，或者干脆不放，只留天空） | 远处只在一个方向出现，而且只要个轮廓 | 不用。背景板从斜的角度看会露出是一张平面 |
| 什么都不放 | 远处被近处的楼完全挡住 | C 往东看，对面楼挡死了，远处不用管 |

远景体块**不做细节**：方块上没有窗户，模型会按母图的样子把它画成一栋栋暗轮廓的楼。做了细节反而会被照着画死。

### 3. 街的两头都要搭

只搭"看过去那一头"，反打转过来身后就是空的，成图会自己发明一条街、一片空地或者天边。这一例南北两头各搭了一排横街对面的楼，A 和 B 的尽头都有东西挡住。

### 4. 白模里不放、只在提示词里写的东西

- **雨和反光**：白模里没有。每张卡写"路面湿透、有浅积水、倒映灯光"。场景图里的雨丝会被定格成静止的线，后面出视频时由视频提示词加会动的雨更自然（这条是经验建议，本示例没有实测）。
- **招牌**：白模里只有一块板，提示词写"空白的旧招牌板"。不写空白，模型会在每块招牌上编字。
- **电线**：白模里没搭，提示词写"没有电线和电线杆"。白模里没有的细线，每个角度会各画各的，前后对不上；剧情需要电线，就在白模里用细长方块搭出来，再写进卡里。
