# Backlot 片场 v1.4.1

> 作者：Manson AIGC
> 许可：CC BY 4.0，免费分享。可以自由转发、修改、商用，请保留上面这行署名。

一套给 AI 智能体用的**场景搭建技能**：一张母图定材质和光，Blender 白模定空间和机位，再派生出同一个场景的多个角度。正打、反打、俯视都对得上同一个空间，不会出现门换了位置、灯多了几盏、桌子转了方向这些问题。

## 它在流程里的位置

```
拿到剧本 → 拆分镜 → 【搭场景：Backlot 片场】 → 出镜头（视频 / 图片）
```

剧本和分镜用你自己的方法或技能做，这套技能不管。它接你任何格式的分镜，最后交出一张「角度 → 场景图」对照表，给你已有的分镜、视频提示词技能挂参考图用。

## 怎么装

**Claude Code**：把整个 `backlot` 文件夹放进 `~/.claude/skills/`（所有项目都能用），或项目里的 `.claude/skills/`（只这个项目用）。重开会话后生效。

**Codex**：把整个文件夹放进 Codex 的技能目录，常见位置是 `~/.codex/skills/`，有的版本用 `~/.agents/skills/`。以你用的版本的官方说明为准。

**Claude 网页版 / 桌面版**：把 `backlot` 文件夹打成 zip（zip 里第一层就是这个文件夹，文件夹名不要改），到设置里的技能页面上传。需要先打开"代码执行 / 创建和编辑文件"。菜单位置会随版本变，以 Claude 帮助中心的说明为准。

**豆包、扣子、ChatGPT、Kimi 等不能装技能文件夹的**：用 `Backlot片场_v1.4.1_单文件版.md`。

- 对话开头把整份内容贴进去，或者作为文件上传，说"按这份技能帮我搭场景"。
- 做智能体 / Bot 的，可以把它放进知识库，或者放进人设与提示词。
- 这类平台一般跑不了 Blender，智能体会带你走 B 档（你自己在 Blender 里照着搭）或 C 档（画草图兜底）。

## 需要准备什么

- **一个能同时挂 2 张参考图的生图模型**（派生图要用）。只出母图的话，任何生图模型都行。
- **Blender**（推荐，免费）：blender.org 下载。没有也能用，走草图兜底，控制力弱一些。
- **Python + Pillow**（可选）：跑叠图和像素对比脚本用，`pip install pillow`。反推母图机位的脚本另外要 numpy：`pip install numpy`。

## 怎么用

装好后直接对你的智能体说，比如：

> 用 Backlot 片场帮我搭这个场景：（贴剧本片段或分镜）

智能体会先问你用哪个生图模型、能不能跑 Blender，然后按七步走：列角度清单 → 写设定卡 → 出母图 → 搭白模 → 出派生图 → 自检返修 → 定版交付。

**花钱的提醒写在技能里**：真正生成前，智能体会先说一声用哪个模型、出几张，默认一次只出 1 张。想知道大概多少钱，问它就行。
